## Learning Path

A practical progression for this collection is:

1. **Begin with discovery** — learn to identify useful information and potential entry points.
2. **Practice enumeration** — investigate users, lists, files, and exposed resources.
3. **Study SSH** — understand the role of SSH in Linux administration and CTF environments.
4. **Analyze credentials** — identify how discovered information can affect authentication.
5. **Work with wordlists** — understand how lists support controlled security testing.
6. **Explore authentication testing** — practice Hydra-related concepts only inside authorized labs.
7. **Combine the workflow** — connect discovery, enumeration, credential analysis, and SSH investigation.
